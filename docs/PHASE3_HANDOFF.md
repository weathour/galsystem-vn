## Phase 3 objective

Complete a local playable MVP for **Narcissu 1** and **Narcissu Side 2nd** in Godot using legally obtained local game data.

The target is **not** a full general-purpose NScripter emulator. The target is a pragmatic Narcissu-compatible runtime subset that can read the current private converted script, resolve local resources, show original images, play music/SFX/voice, advance text, and preserve the existing galsystem save/backlog/auto/skip shell.

## Non-negotiable boundary

Third-party story text and assets must remain private and ignored by Git.

Keep these under ignored paths:

```text
reference_private/narcissu/
external_reference/
```

Do not commit:

- full Narcissu `.galscript` outputs;
- downloaded archives;
- extracted `0.utf`;
- original images/audio/fonts;
- generated manifests that expose complete copyrighted asset inventories, unless later explicitly approved.

Commit only:

- import/extraction tools;
- runtime code;
- docs;
- tests/smokes that skip when private files are absent;
- small synthetic fixtures created by us.

10. Add a final Phase 3 handoff update and commit.

## Recommended implementation shape

Keep `VNDirector.gd` from growing further. Add dedicated systems:

```text
scripts/systems/NarcissuAssetResolver.gd
scripts/systems/NarcissuCommandExecutor.gd
scripts/systems/NarcissuRuntimeProfile.gd
scripts/systems/NarcissuManifest.gd          # optional if resolver can own it
```

Recommended responsibilities:

### `NarcissuAssetResolver.gd`

- Load a private manifest when present.
- Resolve NScripter-style paths such as `haeleth\2\h000.png`, `bgm2\2sou01.mp3`, `se\ele2.ogg`.
- Normalize path separators and case.
- Return `res://reference_private/...` paths or empty strings.
- Provide missing-asset diagnostics.

### `NarcissuCommandExecutor.gd`

- Execute Narcissu-specific commands produced by the converter.
- Dispatch image/audio commands to the presentation shell.
- Preserve existing generic `.galscript` commands where possible.
- Avoid embedding Narcissu text or asset data in committed code.

### `NarcissuRuntimeProfile.gd`

- Store Narcissu display defaults:
  - 800x600 source layout;
  - text window profile;
  - default image fit mode;
  - audio bus names;
  - fade/wait defaults.

## Risks and handling

1. **Steam/latest package may use a different engine/data layout.** Prefer the known PONScripter/Neechin package first because it exposes `0.utf` and direct paths. If Steam differs, map it as an additional source, not the first blocker.
2. **Godot import may not import ignored private assets automatically.** If `res://reference_private/...` does not import cleanly, load private files via absolute/user paths and `Image.load_from_file()` / audio stream loaders where possible.
3. **Some NScripter commands may be complex.** Implement observed Narcissu subset only; log and skip low-impact commands.
4. **Headless audio assertions can be tricky.** In smoke tests, verify streams resolve/load rather than requiring audible playback.
5. **Copyright boundary.** Never paste full script excerpts into committed docs/tests. Use synthetic fixtures for committed tests.

## Stop condition for Phase 3

Stop and commit when Narcissu 1/2 can be launched from Godot using local private data, shows real media, advances text, handles common commands safely, and passes the full validation suite above.
